# Room Booking App

A simple room booking demo built with HTML, CSS and JavaScript.

## Features
- Search room types by guest capacity
- Display room descriptions and nightly prices
- Booking date validation and test cases

## Run
Open `index.html` in a modern browser.

Run booking validation tests with:

```bash
node booking-validation.test.js
```
